## Зачем создан FKVideoPlayer?

Большинство существующих видеопрограмм бросаются в крайности:
- **Обычные плееры (VLC, MPC-HC, mpv)** отлично воспроизводят фильмы, но в них нельзя нарисовать стрелку прямо на кадре, приблизить пиксели в игре, наложить референс поверх видео или записать аннотации со звуком.
- **Тяжелые видеоредакторы (Premiere, DaVinci, After Effects)** грузятся минутами, весят десятки гигабайт и требуют создания целого проекта, просто чтобы покадрово найти баг, обвести его кистью и выгрузить 5-секундный клип.
- **Инструменты захвата экрана (OBS Studio)** сложны в настройке, когда нужно быстро захватить окно конкретной программы, записать системный звук через WASAPI и прокомментировать микрофоном.

**FKVideoPlayer** закрывает эту нишу. Это компактный автономный инструмент в одном файле для разработчиков игр, тестировщиков (QA), видеомонтажеров и создателей контента, которым нужен мгновенный покадровый анализ и рисование на экране без тяжелого софта.

## Ключевые возможности

### 1. Покадровая точность и субпиксельный зум
- **Аппаратное декодирование:** Быстрые декодеры PyAV (FFmpeg) и OpenCV с асинхронной подгрузкой кадров и управлением памятью через LRU-кэш.
- **Микрошаги:** Точный переход кадр-за-кадром вперед и назад (`Стрелки`, клавиши `,` / `.`).
- **Плавное изменение скорости:** Воспроизведение от ультра-замедленного **0.05x** до ускоренного **10.0x**.
- **Глубокий зум и панорамирование:** Масштаб от 10% до 50x, режим пиксель-в-пиксель 1:1 (`1`) и подгонка под размер окна (`F`).

### 2. Мульти-трековый таймлайн оверлеев
- **Независимые дорожки:** Добавляйте видео, GIF, изображения и текст поверх холста. У каждого объекта появляется собственная полоса на таймлайне со скраббером, кнопкой скрытия, фиксацией пропорций и удалением.
- **Картинка в картинке (PIP):** Свободно перемещайте, масштабируйте и вращайте наложенные видеоклипы.
- **Массовое выделение рамкой:** Выделяйте несколько объектов прямоугольной рамкой и управляйте ими одновременно.

### 3. Стерка в стиле Photoshop и векторные аннотации
- **Частичное стирание:** Ластик физически прорезает и удаляет нужные части нарисованных линий с регулируемым радиусом (клавиши `[` и `]`), как в Photoshop и Paint, а не удаляет весь штрих целиком.
- **Инструменты рисования:** Кисть, маркер-хайлайтер, стрелки, прямоугольники, круги и текстовые блоки.
- **Рекордер действий:** Записывает движения курсора, штрихи и манипуляции с точностью до миллисекунды для мгновенного экспорта в видео или сохранения в JSON.

### 4. Прямой захват окон и запись звука WASAPI
- **Стриминг окон Windows:** Подключайтесь к любому запущенному приложению (играм, браузерам, эмуляторам) и захватывайте кадры прямо на холст через оптимизированный Win32 GDI без утечек дескрипторов.
- **Системный звук WASAPI Loopback:** Запись звука из игры или приложения напрямую из аудиопотока Windows без виртуальных аудиокабелей.
- **Запись микрофона:** Голосовые комментарии с живым индикатором громкости (VU-meter).

### 5. Мульти-проектные вкладки (Табы)
- Открывайте и редактируйте несколько видео, чистых холстов или захватов окон одновременно во вкладках с изолированными таймлайнами, стеками отмены и настройками.

## Запуск из исходников

### Требования
- Windows 10 или Windows 11 (64-bit)
- Python 3.10 – 3.13

### Быстрый старт
```bash
# 1. Клонирование репозитория
git clone https://github.com/furrykit/FKVideoPlayer.git
cd FKVideoPlayer

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Запуск программы
python -m fkplayer
# или
python player.py
```

### Запуск тестов
Все 47 автотестов работают локально без внешних зависимостей:
```bash
python -m unittest test_player.py
```

### Сборка автономного EXE
```bash
pyinstaller FKVideoPlayer.spec --clean -y
```
Готовый бинарник будет лежать в `dist/FKVideoPlayer.exe`.

## Горячие клавиши

| Сочетание | Действие |
|:---|:---|
| `Space` | Воспроизведение / Пауза |
| `Left` / `Right` | Шаг на -1 / +1 кадр |
| `Ctrl + Left` / `Right` | Перемотка на -1.0с / +1.0с |
| `Shift + Left` / `Right` | Перемотка на -5.0с / +5.0с |
| `Home` / `End` | В начало / В конец видео |
| `F` | Вписать в окно |
| `1` | Масштаб 1:1 (пиксель в пиксель) |
| `Ctrl + Z` | Отменить последнее действие |
| `C` | Очистить все рисунки |
| `[` / `]` | Уменьшить / Увеличить размер кисти или стерки |
| `Delete` / `Backspace` | Удалить выбранные оверлеи |
| `Ctrl + T` | Новая вкладка проекта |
| `Ctrl + W` | Закрыть текущую вкладку |
| `Ctrl + N` | Создать чистый холст |
| `Ctrl + O` | Открыть видеофайл |
| `Ctrl + E` | Экспорт видео / записи действий |

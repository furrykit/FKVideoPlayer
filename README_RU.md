## Зачем создан FKVideoPlayer?

Большинство видеопрограмм созданы либо для пассивного просмотра, либо для сложного продакшена:
- **Обычные плееры (VLC, MPC-HC, mpv)** заточены под просмотр фильмов: в них нельзя нарисовать стрелку прямо на кадре, приблизить пиксели в игре, наложить референсный ролик поверх видео или записать аннотации со звуком.
- **Тяжелые видеоредакторы (Premiere, DaVinci, After Effects)** грузятся минутами, занимают гигабайты памяти и требуют создания целого проекта, просто чтобы покадрово найти баг, обвести его кистью и выгрузить 5-секундный клип.
- **Инструменты захвата экрана (OBS Studio)** избыточны и сложны в настройке, когда нужно быстро захватить окно конкретной программы или монитор целиком, записать системный звук через WASAPI и нарисовать пояснения прямо поверх картинки.

**FKVideoPlayer** закрывает эту нишу: компактный автономный инструмент в одном файле для разработчиков игр, тестировщиков (QA), видеомонтажеров и создателей контента, которым нужен мгновенный покадровый анализ, рисование на экране и захват без лишнего софта.

## Ключевые возможности

### 1. Аппаратное ускорение и покадровая точность
- **Аппаратное декодирование (NVDEC / CUDA):** Автоматическое ускорение GPU (`hevc_cuvid`, `h264_cuvid`, `vp9_cuvid`, `av1_cuvid`) с масштабированием на лету для плавного воспроизведения 4K и 8K видео при 60 FPS.
- **Программный фоллбэк:** Многопоточный движок PyAV / FFmpeg для гарантированной работы на любых конфигурациях процессоров.
- **Микрошаги:** Точный переход кадр-за-кадром вперед и назад (`Стрелки`, клавиши `,` / `.`).
- **Плавное изменение скорости:** Воспроизведение от замедленного **0.05x** до ускоренного **10.0x** с синхронизацией аудио.
- **Глубокий зум и панорамирование:** Масштаб от 10% до 50x, режим пиксель-в-пиксель 1:1 (`1`) и подгонка под размер окна (`F`).

### 2. Интерактивное вращение на 360° и мульти-трековый таймлайн
- **Свободное вращение элементов:** Маркер вращения над рамкой выделения. Вращайте на любые 360° рисунки кистью, текст, изображения и видеоролики. Удержание `Shift` фиксирует шаг поворота по 15°.
- **Независимые дорожки оверлеев:** Добавляйте видео, GIF, изображения и текст поверх холста. У каждого объекта своя дорожка на таймлайне со скраббером, кнопкой скрытия, фиксацией пропорций и удалением.
- **Картинка в картинке (PIP):** Свободно перемещайте, масштабируйте, кадрируйте и наслаивайте вторичные видеоклипы.
- **Массовое выделение рамкой:** Выделяйте группу объектов прямоугольной рамкой для совместного перемещения, вращения или удаления.
- **Единая история отмены (Undo/Redo):** `Ctrl + Z` восстанавливает не только рисунки, но и перемещения, трансформации, вращение и удаленные оверлеи.

### 3. Стерка в стиле Photoshop и векторные аннотации
- **Частичное стирание линий:** Ластик физически прорезает штрихи и удаляет только пересекаемые участки с регулируемым радиусом (клавиши `[` и `]`), как в Photoshop и Paint, а не удаляет всю линию целиком.
- **Отмена стирания в один шаг:** Непрерывное стирание нескольких штрихов за одно движение мыши откатывается одним нажатием `Ctrl + Z`.
- **Инструменты рисования:** Кисть, маркер-хайлайтер, прямые стрелки, прямоугольники, круги и текстовые блоки.
- **Рекордер действий:** Записывает движения курсора, штрихи и манипуляции с точностью до миллисекунды для мгновенного экспорта в видео или сохранения в JSON.

### 4. Захват мониторов и окон со звуком WASAPI
- **Два режима захвата:** Захват отдельного окна любой запущенной программы или захват экрана / виртуального рабочего стола целиком на мульти-мониторных конфигурациях.
- **Минимальная задержка:** Оптимизированный движок Win32 GDI BitBlt (~2 мс задержка снятия кадра, до 60 FPS) без утечек дескрипторов GDI.
- **Системный звук WASAPI Loopback:** Запись звука из игр и программ напрямую из аудиопотока Windows без виртуальных аудиокабелей.
- **Запись микрофона:** Голосовые комментарии параллельно со звуком системы с живым индикатором уровня громкости (VU-meter).

### 5. Мульти-проектные вкладки и портативная сборка
- **Изолированные вкладки:** Открывайте и редактируйте несколько видео, чистых холстов или захватов экранов одновременно во вкладках с независимыми таймлайнами и стеками отмены.
- **Автономный EXE:** Один исполняемый файл без необходимости установки Python, библиотек или стороннего FFmpeg.

## Запуск из исходников

### Требования
- Windows 10 или Windows 11 (64-bit)
- Python 3.10 – 3.13

### Быстрый старт
```bash
# 1. Клонирование репозитория
git clone https://github.com/furrykit/FKVideoPlayer.git
cd FKVideoPlayer

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Запуск программы
python -m fkplayer
# или
python player.py
```

### Запуск тестов
Все 57 автотестов работают локально без внешних зависимостей:
```bash
python -m unittest discover tests
# или
python -m unittest tests/test_player.py
```

### Сборка автономного EXE
```bash
pyinstaller FKVideoPlayer.spec --clean -y
```
Готовый бинарник будет скомпилирован в `dist/FKVideoPlayer.exe`.

## Горячие клавиши

| Сочетание | Действие |
|:---|:---|
| `Space` | Воспроизведение / Пауза |
| `Left` / `Right` | Шаг на -1 / +1 кадр |
| `,` / `.` | Шаг на -1 / +1 кадр |
| `Ctrl + Left` / `Right` | Перемотка на -1.0с / +1.0с |
| `Shift + Left` / `Right` | Перемотка на -5.0с / +5.0с |
| `Home` / `End` | В начало / В конец видео |
| `F` | Вписать в окно |
| `1` | Масштаб 1:1 (пиксель в пиксель) |
| `Ctrl + Z` | Отменить действие (рисование, стерка, перемещение, вращение, удаление) |
| `C` | Очистить все рисунки |
| `[` / `]` | Уменьшить / Увеличить размер кисти или стерки |
| `Shift + Перетаскивание поворота` | Фиксация угла поворота с шагом 15° |
| `Delete` / `Backspace` | Удалить выбранные оверлеи |
| `Ctrl + T` | Новая вкладка проекта |
| `Ctrl + W` | Закрыть текущую вкладку |
| `Ctrl + N` | Создать чистый холст |
| `Ctrl + O` | Открыть видеофайл |
| `Ctrl + E` | Экспорт видео / записи действий |
